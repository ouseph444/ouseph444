**Tech Stack:** `Python` `Plotly Dash` `NumPy` `SciPy` `Jupyter Notebook`

**Key Highlights:**

- 📊 Interactive multi-panel dashboard: potential V(φ) plots, (ε,η) phase space, nₛ–r constraint plane with Planck/BICEP exclusion bands, scalar power spectrum 𝒫ᵣ(k)
- 🎓 Serves as both a research communication tool and graduate-level teaching aid with annotated tooltips
