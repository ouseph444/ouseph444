### ⚛️ LHC Data Analysis Pipeline

> **End-to-end HPC pipeline for rare-signal extraction** from multi-terabyte LHC simulations — theory → generation → detector simulation → ML classification → published exclusion limits.

[![View Repo](https://img.shields.io/badge/View_Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/ouseph444/LHE-file)
![Stack](https://img.shields.io/badge/Python_·_ROOT_·_MadGraph_·_Pythia_·_Scikit--learn_·_TensorFlow-0f172a?style=flat-square)

```
Theoretical model (FeynRules / Mathematica)
    → Event generation  (MadGraph5 + Pythia8)
    → Detector simulation  (Delphes)
    → Feature engineering on kinematic variables  (Python / ROOT)
    → Signal/background classification  (Scikit-learn / TensorFlow)
    → Likelihood ratios + confidence intervals
    → Publication-quality exclusion limits
```
