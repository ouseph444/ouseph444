### 📈 Inflation Explorer — Cosmological Visualisation Tool

> **An interactive research dashboard for inflationary cosmology**, letting users sweep model parameters in real time and compare predictions against Planck 2018 and BICEP/Keck observational constraints.

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github)](https://github.com/ouseph444/Inflation-Explorer)
![Stack](https://img.shields.io/badge/Python_·_SciPy_·_Plotly_Dash_·_NumPy_·_Jupyter-1e293b?style=flat-square)

**Why it exists:** Inflationary models involve abstract mathematics that is hard to communicate — even to physicists. Static paper figures can't show how predictions shift as parameters change.

**What it does:**

| Panel | Physics | Method |
|:---|:---|:---|
| V(φ) potential | Scalar field potential landscape | Matplotlib/Plotly parametric plot |
| (ε, η) phase space | Slow-roll parameter evolution | `scipy.odeint` on Klein-Gordon + Friedmann |
| nₛ–r constraint plane | Observational exclusion regions | Planck 2018 & BICEP/Keck as shaded bands |
| 𝒫ᵣ(k) power spectrum | Scalar power spectrum shape | Numerical integration with `scipy.quad` |

**Technical highlights:**
- Analytical derivations cross-checked against full numerical solutions for physics-grade precision
- Hover tooltips explain the physical meaning of every parameter — usable as a teaching tool
- PNG/SVG export from every panel; usable in lectures and publications

### 🔬 LHC Data Analysis Pipeline — Collider Phenomenology

> **End-to-end HPC analysis pipeline** for rare-signal extraction from multi-terabyte LHC simulations — from theoretical model definition through to published exclusion limits.

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github)](https://github.com/ouseph444/LHE-file)
![Stack](https://img.shields.io/badge/Python_·_ROOT_·_MadGraph_·_Pythia_·_Scikit--learn_·_TensorFlow-1e293b?style=flat-square)

**The pipeline:**

```
Theoretical model (FeynRules / Mathematica)
        ↓
Event generation (MadGraph5 + Pythia8)
        ↓
Detector simulation (Delphes)
        ↓
Feature engineering on kinematic variables (Python / ROOT)
        ↓
Signal/background classification (Scikit-learn / TensorFlow)
        ↓
Statistical analysis: likelihood ratios, confidence intervals
        ↓
Publication-quality figures + exclusion limits
```

**Scale & impact:**
- 12 completed HPC projects across LHC, DUNE, and Forward Physics Facility
- >10TB of simulated data processed across Linux cluster environments
- Methods adopted by experimental collaborations for data filtering strategies
- Results published in JHEP, Phys. Rev. D, Eur. Phys. J. C

**Visualisation types produced:** ROC curves · invariant mass distributions · Dalitz plots · lego plots · correlation heatmaps · contour plots · Brazil band limit plots · stacked histograms · cut-flow tables · scatter/surface plots
